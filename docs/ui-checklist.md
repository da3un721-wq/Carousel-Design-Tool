## 1. 페이지 (전체 화면)

- [ ] **스플래시** (앱 실행 시)
- [ ] (보류) **튜토리얼**: 첫 실행일 때만 진행. 내용은 앱 설계가 끝난 뒤 설계
- [ ] **S1 홈 · 전체**: "CaroKit ▾" + 보기 탭(전체 / 시리즈 / 템플릿·레퍼런스 추후) + **핀터레스트식 4칸 그리드** (첫 칸 + 새 프로젝트, 카드 넘겨 보기)
- [ ] **S1-1 홈 · 설정 팝업**: 내 프로필, 설정 항목, 가져오기 · 휴지통 · 정보
- [ ] **S1-2 홈 · 시리즈별**: 폴더 탭 모양 시리즈 카드 2열
- [ ] **S2 시리즈 상세**: 이름(폴더 탭), 제목 형식(넘버링 / 부제), 시리즈 설정 4칸(비율 · 폰트 · 컬러 · 브러쉬), 회차 격자(첫 칸 + 새 회차)
- [ ] **S2-1 시리즈 설정 들어가기**: 칸마다 일괄 설정 화면 (비율 / 폰트 / 컬러 / 브러쉬, 템플릿 · 텍스트 스타일 · 레이아웃 프리셋)
- [ ] **S3 템플릿 보관함**: 내 템플릿 / 시리즈별 / 기본 제공 탭
- [ ] **S4 에디터**: 상단 바, 왼쪽 도구 바, 캔버스, 오른쪽 패널, 하단 슬라이드 바 (상태는 3번)
- [ ] **S5 미리보기**: 피드 / 그리드, 휴대폰 / 크게, 라이트 / 다크, 혼합 / 기본 업로드
- [ ] **S7 설정**: 일반, 펜슬과 제스처, 키보드, 기기, 폰트, 저장과 백업, 정보
- [ ] **S8 휴지통**: 삭제한 프로젝트, 남은 날짜

## 2. 빈 화면 (처음 쓸 때)

- [ ] 홈: 프로젝트가 하나도 없을 때 ("첫 캐러셀 만들기" 안내)
- [ ] 시리즈: 회차가 없을 때
- [ ] 템플릿 보관함: 내 템플릿이 없을 때
- [ ] 휴지통: 비어 있을 때

## 3. 에디터 상태

같은 에디터 화면이지만 무엇을 선택했는지에 따라 오른쪽 패널과 캔버스가 달라져요.

**보기와 모드**

- [ ] 이어 보기 모드 (슬라이드 가로 나열)
- [ ] 한 장씩 보기 모드
- [ ] 손글씨 모드 (왼쪽 도구 바가 브러쉬 도구로 바뀜)
- [ ] 오른쪽 패널: 레이어 탭
- [ ] **원고 패널을 연 상태** (왼쪽, 캔버스가 좁아짐)
- [ ] 원고 단락을 캔버스로 끌어오는 중 (놓을 위치 미리보기)
- [ ] 넣을 위치 지정 모드 (캔버스에서 탭하거나 영역 그리기)
- [ ] 오버레이를 켠 상태 (눈금자, 가이드, 레이아웃 그리드, 썸네일 잘림, 인스타 가림 영역)

**선택에 따른 상태**

- [ ] 아무것도 선택 안 함 / 슬라이드 선택 (슬라이드 채우기, 비율, 레이아웃 그리드)
- [ ] 텍스트 선택
- [ ] 텍스트 편집 중 (커서, 글자 선택 영역, **아이패드 화면 키보드가 올라온 모습**)
- [ ] 이미지 선택
- [ ] 동영상 선택 (재생 컨트롤 + 타임라인)
- [ ] 도형 선택
- [ ] 펜툴로 그리는 중 / 점 편집
- [ ] 말풍선 선택 (꼬리 핸들)
- [ ] 손그림 레이어 선택 (편집 모드에서)
- [ ] 여러 개 선택 (값이 다르면 "혼합" 표시)
- [ ] 크롭 모드 (이미지 / 영상)

## 8. 공통 컴포넌트

각 컴포넌트마다 **상태**를 함께 만들어 주세요: 기본, 눌림, 선택됨, 비활성 (필요한 것만)

**버튼류**

- [ ] 버튼: Primary (내보내기, 만들기, 완료)
- [ ] 버튼: Secondary (미리보기, 취소)
- [ ] 버튼: Ghost / 옅은 버튼 (10초에 맞추기, 건너뛰기)
- [ ] 버튼: 위험 (삭제, 영구 삭제)
- [ ] 텍스트 버튼 ("+ 추가")
- [ ] 아이콘 버튼 (상단 바, 패널)
- [ ] 도구 버튼 (왼쪽 도구 바: 아이콘 + 라벨, 선택 상태)
- [ ] 세그먼트 컨트롤 (이어 보기/한 장씩, 편집/손글씨, 탭 등 2~6칸)

**입력류**

- [ ] 숫자 입력칸 (Figma식: 라벨 + 값 + 단위, 포커스, "혼합" 상태)
- [ ] 드롭다운
- [ ] 검색창
- [ ] 스테퍼 (− 5 +)
- [ ] 토글 + 토글 행 (라벨 + 토글)
- [ ] 가로 슬라이더 (라벨 + 값)
- [ ] 세로 슬라이더 (손글씨 모드 크기/불투명도, Procreate식)
- [ ] 색 스와치 (기본, 선택됨, "+" 추가)

**목록과 카드**

- [ ] 상단 바 띠 (진한 띠 + 칸: 기본 / 열림(흰색, 아래와 이어짐) / 흐림(추후))
- [ ] 장 표시 동그라미 (최대 6개, 6장 넘으면 끝이 작아짐)
- [ ] 섹션 헤더 (제목 + 액션)
- [ ] 프로젝트 카드 (썸네일, 이름, 장수, 수정일)
- [ ] 템플릿 카드 / 시리즈 카드
- [ ] 회차 행 (드래그 핸들, 썸네일, 제목, 메뉴)
- [ ] 레이어 행 (썸네일, 이름, 보이기, 잠금, 선택 / 클리핑 / 그룹 펼침 / 숨김 상태)
- [ ] 슬라이드 썸네일 (기본, 선택, 영상 슬라이드, 드래그 중, + 추가)
- [ ] **원고 단락 블록** (스타일 이름, 기본 / 선택 / 넣음 ✓ / 위치 지정됨 / 캔버스에서 선택해 강조된 상태 / 끌고 있는 상태)
- [ ] 원고 슬라이드 구분선
- [ ] 원고 입력 도구 바 (키보드 없을 때: 단락 나누기, 줄바꿈, 구분선, 넣기)

**캔버스 위 요소**

- [ ] 선택 박스와 핸들 (모서리, 회전)
- [ ] 특수 핸들 (말풍선 꼬리 끝 / 꼬리 폭, 펜툴 점 / 곡선 핸들, 크롭 모서리)
- [ ] 스마트 가이드선, 간격 라벨
- [ ] 확대 % 표시

**기타**

- [ ] 태그 / 배지 ("시리즈", "기본", "새 기능" 등)
- [ ] 진행 바 (내보내기, 영상 결과 길이)
- [ ] 영상 타임라인 (필름 스트립 + 구간 핸들 + 재생 위치)
- [ ] 키캡 (단축키 목록용)

## 9. 화면별 버튼

### 홈 (S1)
CaroKit ▾(설정 팝업) · 보기 탭(전체 / 시리즈 / 템플릿·레퍼런스 추후) · + 새 프로젝트(그리드 첫 칸) · + 새 시리즈 · 정렬(최근순/이름순) · 카드(넘겨 보기, 제목, ··· 메뉴)

### 시리즈 상세 (S2)
뒤로 · 이름 바꾸기 · 제목 형식(넘버링/부제) · 시리즈 설정 4칸 들어가기 · + 새 회차 · 시리즈 내보내기

### 에디터 상단 바 (S4)
뒤로 · 프로젝트 이름(누르면 이름 바꾸기) · 실행 취소 · 다시 실행 · 레이어 · 미리보기 · 내보내기

### 원고 패널

### 에디터 오른쪽 패널
- 선택했을 때만 나타남 (머리에 선택한 것 이름). 레이어는 상단 "레이어" 버튼으로
- 위치·크기: X, Y, W, H, 회전, 모서리 반경, 비율 고정, 기준점
- 정렬: 좌, 가로 중앙, 우, 상, 세로 중앙, 하, 가로 분배, 세로 분배, 좌우 뒤집기, 상하 뒤집기
- 레이어: 불투명도, 블렌드 모드
- 채우기: 단색 / 그라디언트 / 없음, 색, 불투명도
- 테두리: 색, 두께, 위치, 점선
- 효과: 그림자
- 텍스트: 폰트, 굵기, 크기, 색, 자간, 행간, 장평, 굵게, 이탤릭, 밑줄, 취소선, 기울기 각도, 정렬 4종, 세로 정렬 3종, 박스 방식, 줄바꿈 단위, 글자 테두리, 텍스트 스타일, 세로쓰기, 곡선
- 텍스트 배경: 색, 불투명도, 여백, 라운딩(전체/개별), 박스 테두리, 전체 박스/줄마다 박스
- 이미지: 크롭, 프레임 안 위치, 교체, 보정, 모서리, 테두리, 배경 제거
- 말풍선: 원형/네모, 라운딩, 꼬리 폭, 꼬리 없음, 추가 모양
- 동영상: 구간·배속 편집, 배속 5종, 10초에 맞추기, 화면 크롭, 원본 소리 끄기, 오디오 파일, 볼륨, 시작 지점, 페이드 인/아웃, 소리 높낮이 유지
- 슬라이드: 채우기, 비율, 혼합 비율 토글
- 레이아웃 그리드: 열, 행, 여백, 간격, 프리셋 저장, 모든 슬라이드에 적용
- 레이어 탭: 현재 슬라이드만 토글, + 손그림 레이어, 클리핑, 그룹

## 디자인할 때 챙길 것

1. **터치 영역은 최소 44×44pt**: 손가락으로 누르는 앱이라 작은 아이콘도 누르는 범위는 넉넉하게 (애플 권장 기준)
2. **텍스트 편집 중 화면 키보드**: 아이패드 화면 키보드가 올라오면 화면 아래쪽이 가려져요. 슬라이드 바와 캔버스가 어떻게 밀리는지 정해 주세요
3. **세로 화면을 지원할지**: 지금 설계는 가로 기준이에요. 아이패드를 세로로 들었을 때도 쓸지 정하면 레이아웃을 하나 더 만들어야 해요
4. **펜슬 기능이 없는 아이패드**: 호버(DR-15), 스퀴즈(DR-17)는 지원 기기에서만 보이게 할지, 흐리게 보여줄지
5. **다크 모드**: 이번엔 라이트만 해도 되지만, 색을 정할 때 나중에 다크 모드로 바꾸기 쉽게 색 변수(Variables)로 만들어 두면 좋아요
6. **캔버스 영역은 중립색으로**: 작업물 색이 잘 보이도록 UI 색은 절제하고 포인트 컬러는 선택 상태에만
7. **인스타 미리보기**: 인스타 로고와 아이콘을 그대로 쓰지 않기 (상표 문제)

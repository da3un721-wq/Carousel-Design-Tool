# 캐로킷 (CaroKit): UI 설계 목록 (v0.2)

> 직접 UI를 설계할 때 만들어야 하는 것 전부. 와이어프레임 v0.2([Figma › WireFrame v0.2](https://www.figma.com/design/fRGnDrQsZ5Iyh8eUxt5sOx)) · 기능 명세서 v0.10 기준.
> 기준 화면: iPad Pro 13" 가로 1376 × 1032 pt. 스타일 원칙: [디자인 원칙](design-principles.md) 2-1장.
> 체크박스로 진행 상황을 표시하세요.

**추천 순서**: 1 기반(색 · 글꼴 · 간격) → 11 컴포넌트 → 12 아이콘 → 2 화면 → 3 에디터 상태 · 4 편집 패널 → 나머지

## 0. 글 대신 모양으로 알려주는 규칙 (어포던스)

화면에 설명 글을 넣지 않고, 아래 모양 규칙으로 알려준다. 와이어프레임 v0.2에서 설명 글은 모두 이 규칙으로 바꿨다.

| 알려줄 것 | 모양 |
|---|---|
| 지금 보는 곳 · 열린 칸 | 상단 띠에서 **흰 칸**(아래 화면과 이어짐) |
| 선택됨 · 켜짐 | **검정 채움** 또는 **2px 선**, 도구는 왼쪽 2px 막대 |
| 추가할 수 있음 | **점선 칸** (+ 새 프로젝트, 꾸미기 추가, 장 추가) |
| 접혀 있음 · 더 있음 | **셰브론 ▸ ▾** |
| 길게 누르면 숨은 도구 | 도구 칸 오른쪽 아래 **작은 삼각형** |
| 시리즈에서 정해 둔 것 | 검정 **"시리즈" 배지** |
| 넘겨 볼 수 있음 · 몇 번째 장 | **동그라미** (최대 6개, 많으면 끝이 작아짐) |
| 단축키 | 도구 칸 오른쪽 위 **작은 글자** |
| 잘리는 위치 | 장 경계 **재단선 + 점선** (걸쳐도 경고하지 않음, 일부러 걸친 것) |
| 아직 못 씀 (추후) | **흐린 색** |
| 원고와 연결됨 | 연결 아이콘 + 단락 번호 |

- [ ] 아이콘 크기: 도구 22 · 상단 띠 18~22 · 패널 16 · 입력칸 12

## 2. 화면 (전체 화면)

- [ ] **스플래시**
- [ ] (보류) **튜토리얼**: 첫 실행 때만
- [ ] **홈 · 전체**: 상단 띠(CaroKit ▾ · 템플릿 · 시리즈 · 전체) + 핀터레스트식 4칸(첫 칸 큰 +). 화면 제목 · 개수 · 정렬 버튼 없음
- [ ] **홈 · 시리즈별**: + 새 시리즈 · ···(띠와 폴더 탭 사이 가운데) · 폴더 모양 카드 2열, 회차 좌우 넘김
- [ ] **홈 · 템플릿·레퍼런스** (추후, 지금은 흐린 탭만)
- [ ] **설정 팝업** (CaroKit ▾): 내 프로필(인스타 연동 / 연동 전) · 탭 3개 설정 / 다운로드 / 휴지통
- [ ] **설정 화면**: 키보드 단축키 · 펜슬과 제스처 · 계정 연동 · 폰트 관리 · 이미지 관리 (화면 라이트/다크는 팝업 안에서 바로)
- [ ] **내 프로필 편집**: 사진 · 아이디
- [ ] **휴지통** (팝업 탭): 삭제한 프로젝트 카드 가로 2칸, ···에서 복원 · 영구 삭제
- [ ] **시리즈 상세**: 상단 바 없음, 진한 테두리 + 흰 폴더. 폴더 탭(뒤로 · 제목 입력 · 넘버링/부제) · 설정값 줄(이름표 없음) · 회차 격자 가로 4개
- [ ] **시리즈 설정 들어가기** 4장: 비율 / 폰트(텍스트 스타일) / 컬러(팔레트) / 브러쉬
- [ ] **에디터** (상태는 3장)
- [ ] **미리보기**: 피드 / 프로필 그리드 × 휴대폰 크기 / 크게 × 라이트 / 다크 × 혼합 / 기본 업로드 + 올리기 전에 확인
- [ ] **내보내기**: 시트 → 진행 중 → 완료

## 3. 에디터 상태

**보기와 모드**
- [ ] 이어 보기 / 한 장씩 보기
- [ ] 선택 없음 (편집 패널 없음, 캔버스 넓음)
- [ ] 원고 패널 열림
- [ ] 손글씨 모드 (브러쉬 도구 펼침)
- [ ] 레이어 열림 (상단 띠 "레이어" 칸이 흰색, 아래로 패널)
- [ ] 레퍼런스 창 띄움
- [ ] 오버레이 켬 (눈금자, 가이드, 그리드, 그리드 잘림, 인스타 가림 영역)

**선택에 따라** (편집 패널 내용은 4장)
- [ ] 텍스트 선택 / 텍스트 편집 중 (커서, 아이패드 화면 키보드가 올라온 모습)
- [ ] 이미지 선택 / 크롭 모드
- [ ] 동영상 선택 (재생 컨트롤) / 구간 · 배속 편집
- [ ] 도형 선택 / 펜툴로 그리는 중 / 점 편집
- [ ] 말풍선 선택 (꼬리 핸들)
- [ ] 손그림 레이어 선택
- [ ] 여러 개 선택 ("혼합" 값)
- [ ] 슬라이드 선택

**원고 연동**
- [ ] 단락을 캔버스로 끄는 중 (놓을 자리 점선)
- [ ] 넣을 위치 지정 모드
- [ ] 캔버스 글자를 고르면 원고 단락이 강조됨

## 4. 편집 패널 (왼쪽, 도구 바 바로 옆, 선택했을 때만)

배치: 도구 바 | (원고 패널) | 편집 패널 | 캔버스. 손글씨 모드에서는 같은 자리에 브러쉬 도구 + 브러쉬 설정

**모든 종류에 같은 뼈대**를 쓰고, 종류마다 1순위 섹션만 바꾼다. 와이어프레임 03의 텍스트 패널이 이 뼈대.

```
머리      종류 아이콘 · 이름 · (원고 연결) · 잠금 · 숨기기 · ···
1순위     종류별로 가장 자주 쓰는 것 (아래 표)
색        스와치 · HEX · 불투명도 (한 줄)
꾸미기    점선 추가 칸 3개 (누르면 그 섹션이 생김)
위치      접힘. 펼치면 X · Y · W · H · 회전 · 비율 고정 · 정렬
고급      접힘
```

| 종류 | 1순위 | 꾸미기 (점선 칸) | 고급 (접힘) |
|---|---|---|---|
| **텍스트** | 폰트 · 굵기 · 크기 · 행간 · 자간 · [정렬 4 + 굵게 · 기울임 · 밑줄 · 취소선] 아이콘 줄 | 배경 박스 · 테두리 · 그림자 | 장평 · 기울기 각도 · 세로 정렬 · 박스 방식 · 줄바꿈 · 세로쓰기 · 곡선 · 블렌드 · 스타일로 저장 |
| **이미지** | 교체 · 크롭 · 프레임 안 위치 · 보정(밝기 · 대비 · 채도 · 색온도 · 흐림) | 테두리 · 그림자 · 모서리 | 배경 제거 · 블렌드 · 불투명도 |
| **동영상** | 재생 · 구간 · 배속(10초에 맞추기) · 크롭 · 소리(원본 끄기 · 오디오 파일 · 볼륨) | 테두리 · 모서리 | 페이드 · 높낮이 유지 · 블렌드 |
| **도형 · 펜툴** | 채우기 · 테두리(두께 · 위치 · 점선) · 모서리 | 그림자 | 도형 합치기 · 블렌드 |
| **말풍선** | 모양(원형 · 네모 · 생각 · 외침) · 꼬리 없음 · 글자(텍스트와 같음) | 테두리 · 그림자 | 블렌드 |
| **손그림 레이어** | 불투명도 · 블렌드 · 클리핑 | | |
| **여러 개** | 정렬 · 분배 (1순위로 올라옴), 값이 다르면 "혼합" | | |
| **슬라이드** | 채우기 · 비율 · 레이아웃 그리드 | | |

**손글씨 모드 패널**: 시리즈 브러쉬 → 브러쉬 미리보기 → 크기 · 불투명도 · 손떨림 보정 → 필압 · 기울기 · 직선 보정 (네모 토글) → 손그림 레이어 → 고급(질감, 간격, 프리셋 저장)

## 5. 바 구성

**상단 띠 (공통)**: 진한 띠 + 칸. 지금 보는 탭 · 열린 칸만 흰색
- [ ] 홈: CaroKit ▾ · 템플릿(흐림) · 시리즈 · 전체
- [ ] 시리즈 상세: ← 시리즈 · 이름 · 시리즈 내보내기 · 새 회차
- [ ] 에디터: ← 홈 · 프로젝트 이름(누르면 이름 바꾸기) · 실행 취소 · 다시 실행 · 레이어 · 미리보기 · 내보내기
- [ ] 미리보기 · 내보내기: ⚠️ 아직 띠 규칙 미적용 (토글이 많아 배치 결정 필요)

**에디터 왼쪽 도구 바**: 선택 · 텍스트 · 원고 · 미디어(사진 · 영상) · 손글씨 · 요소(말풍선 · 도형 · 펜툴 · 클리핑) · (빈칸) · 레퍼런스

**손글씨 브러쉬 도구** (손글씨를 누르면 옆에 펼침): 펜 · 붓펜 · 형광펜 · 연필 · 지우개 · 올가미 · 스포이드 · 색 + 캔버스 왼쪽 세로 슬라이더(크기 · 불투명도)

**에디터 아래 바**: 장 번호(02 / 10) · 슬라이드 썸네일 · + 추가 · [한 장씩 · 이어 보기] · 배경 · 비율 · 확대 %

**원고 패널**: 머리(원고 · 단락 수 · 닫기) · [전체 · 안 넣은 것] · 자동 흘려넣기 · 장 구분선 · 단락 블록 · 아래(고른 단락 스타일 · 모두 적용 · 단락 나누기 · 줄바꿈 · 장 나누기)

## 6. 팝오버 (버튼 옆 작은 창)

## 11. 컴포넌트 (상태 함께: 기본 · 눌림 · 선택 · 비활성)

**바와 버튼**
- [ ] 상단 띠 칸 (아이콘 + 이름 / 아이콘만) · 기본 / 열림(흰색) / 흐림
- [ ] 도구 칸 (아이콘 + 이름 + 단축키 글자 + 숨은 도구 삼각형) · 기본 / 선택
- [ ] 버튼: 주요(검정) · 보조(선) · 위험
- [ ] 아이콘 버튼 (32 / 36)
- [ ] 세그먼트 (2~4칸)
- [ ] 아이콘 줄 (정렬 · 서식처럼 붙은 아이콘 칸)

**입력**
- [ ] 입력칸 (아이콘 + 숫자, "혼합" 상태)
- [ ] 선택칸 (값 + ▾)

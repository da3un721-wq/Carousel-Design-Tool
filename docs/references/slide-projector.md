# 레퍼런스: 회전식 슬라이드 프로젝터 (Kodak Carousel)

> 캐로킷 UI 콘셉트(툴 키트 × 슬라이드 프로젝터)를 위한 이미지 레퍼런스 모음.
> 이미지는 각 페이지에서 확인할 수 있어요. 무드보드에는 참고용으로만 쓰고, 앱 화면이나 아이콘에 그대로 쓰지 않기 (저작권, 상표).

## UI로 가져올 만한 요소

| 프로젝터 요소 | 캐로킷 UI 아이디어 |
|---|---|
| 원형 트레이와 칸 번호 (80칸) | 슬라이드 번호 표시, 장수 표시(1/20), 로딩 표시 |
| 슬라이드 마운트 (흰 테두리 정사각 프레임) | 하단 슬라이드 바 썸네일, 템플릿 카드 |
| 트레이가 한 칸씩 돌아가는 동작 | 슬라이드 넘김 애니메이션, "찰칵" 소리와 진동 |
| 영사되는 빛 | 미리보기 화면을 열 때 밝아지는 연출 |
| 앞/뒤 버튼, 레버 | 미리보기 넘김 버튼, 토글의 손맛 |
| Carousel-S의 울름 디자인 | 절제된 회색 톤, 기능적인 버튼 배치, 작은 신호색 하나 |

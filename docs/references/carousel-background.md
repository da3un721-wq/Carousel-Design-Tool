# 배경 지식: "캐러셀"이라는 말과 형식의 역사

> 캐로킷 개발과 브랜딩의 바탕이 되는 지식. 웹 검색으로 여러 출처를 교차 확인했고, 정확도를 표시했다.
> 브랜드 문구나 소개 글에 쓸 때는 **✅ 확실** 항목 위주로 쓰고, 🟡·⚠️ 항목은 "~라고 알려져 있다" 식으로 표현하는 것을 권장한다.

### 정확도 표시

| 표시 | 뜻 |
|---|---|
| ✅ 확실 | 1차 자료(공식 발표, 박물관 기록)나 여러 신뢰할 만한 출처가 일치 |
| 🟡 대체로 맞음 | 2차 자료가 일치하지만 1차 자료로 직접 확인하지 못함 |
| ⚠️ 불확실 | 출처끼리 다르거나, 한 사람의 주장이거나, 추정 |

## 한눈에 보는 연표

| 연도 | 사건 | 정확도 |
|---|---|---|
| 1640년대 | 영어에 "carousel"(기마 시합)이라는 말이 들어옴 | ✅ |
| 18~19세기 | 기마 시합 → 놀이공원 **회전목마**로 뜻이 옮겨감 | 🟡 |
| 1961 | Kodak 첫 회전식 슬라이드 프로젝터 **Carousel 550** 출시 | ✅ (1962라는 자료도 있음) |
| 1963 | 독일 Kodak AG의 **Carousel-S** (한스 구겔로트 · 라인홀트 해커 디자인), 이후 MoMA 소장 | ✅ |
| 2004 | Kodak 슬라이드 프로젝터 생산 종료 | ✅ |
| 2007 | 드라마 매드맨 시즌 1 마지막 화 "The Wheel" (캐러셀 피치 장면) | ✅ (드라마, 허구) |
| 2014 | 페이스북 "멀티 프로덕트 광고" 출시 → 이후 **"캐러셀 광고"** 로 이름 변경 | 🟡 (날짜는 자료마다 다름) |
| 2014.4 | 미국 Vox Media "카드 스택" (카드뉴스의 해외 원조로 꼽힘) | 🟡 |
| 2014.9~ | 한국 언론사가 카드뉴스 형식 시작 (스브스뉴스 등) | 🟡 |
| 2015.3 | **인스타그램 캐러셀 광고** 출시 (미국, 일부 광고주) | ✅ |
| 2017.2.22 | 인스타그램 일반 사용자도 **한 게시물에 최대 10장** 가능 | ✅ (인스타그램 공식 발표) |
| 2024.8 | 최대 **20장**으로 늘어남 | 🟡 (언론 보도 일치, 공식 보도자료는 못 찾음) |

## 1. "캐러셀"이라는 단어

| 내용 | 정확도 |
|---|---|
| 영어 carousel은 **프랑스어 carrousel**에서 왔고, 프랑스어는 **이탈리아어 carosello**(나폴리 방언 carusello)에서 왔다 | ✅ |
| 1640년대 영어에서 처음 뜻은 **기사들의 기마 시합, 놀이 같은 마상 대회** | ✅ |
| 이탈리아어 원래 뜻은 "공놀이의 한 종류"(진흙 공을 쓰는 놀이)로 설명된다 | 🟡 |
| 더 먼 어원(라틴어 carrus "수레" 설 등)은 **확실하지 않다** | ⚠️ (사전들이 "불확실"로 표시) |
| 놀이공원 **회전목마** 뜻은 나중에 생겼다. 기마 시합 연습용 장치가 놀이기구로 바뀌어 간 것으로 설명된다 | 🟡 |

**정리**: 캐러셀은 원래 "말을 타고 빙글빙글 도는 시합"에서 "회전목마"가 된 말이다. 이후의 모든 캐러셀(프로젝터, 공항 수하물 컨베이어, 웹 슬라이더, 인스타 게시물)은 **"빙글빙글 돌며 차례로 보여준다"** 는 회전목마의 이미지를 빌려 쓴 것이다.

## 2. Kodak Carousel (회전식 슬라이드 프로젝터)

### 무엇인가

| 내용 | 정확도 |
|---|---|
| 35mm 슬라이드(사진 필름 한 장을 틀에 끼운 것)를 원형 트레이에 꽂아 차례로 벽에 비추는 프로젝터 | ✅ |
| 트레이는 **80장 또는 140장** 들이 | ✅ |
| 슬라이드가 **중력으로 아래 영사 칸에 떨어지는** 방식. 그 전 프로젝터는 일자형 트레이에서 슬라이드를 들어 올려서 휜 슬라이드가 자주 걸렸다 | 🟡 |
| 이름의 이유: 트레이가 **회전목마처럼 눕혀져서 돈다** | 🟡 (위키백과 설명. Kodak의 공식 설명은 못 찾음) |

### 누가 만들었나

| 내용 | 정확도 |
|---|---|
| 첫 모델 **Carousel 550**은 **1961년** 출시 (영국 과학박물관 소장 기록 "Model 550R, 1961") | ✅ (일부 자료는 1962년) |
| 원래 아이디어는 나폴리 출신 이탈리아계 미국인 **루이스 미수라카(Louis Misuraca)** 가 Kodak에 일시금을 받고 팔았다 | ⚠️ (위키백과 등 여러 곳에 나오지만 1차 자료 미확인) |
| 프로젝터 특허는 Kodak 산업디자이너 **데이비드 E. 핸슨(David E. Hansen)** 이름으로 1965년 등록, 원형 트레이 특허는 1962년 출원 · 1966년 등록 | ⚠️ (자료끼리 날짜 설명이 엇갈림) |
| 독일 Kodak AG의 전문가용 **Carousel-S(1963)** 는 울름 조형대학 출신 **한스 구겔로트 · 라인홀트 해커** 가 디자인. 도장 알루미늄과 플라스틱, **MoMA 영구 소장품** | ✅ (MoMA 기록) |

### 언제까지

| 내용 | 정확도 |
|---|---|
| 1960~90년대 강의, 회의, 가족 사진 상영의 표준 기기 | ✅ |
| 디지털 카메라와 디지털 프로젝터에 밀려 **2004년** 생산 종료. Kodak은 2003년에 "2004년 6월 생산 중단" 계획을 알렸다 | ✅ |
| 마지막 생산품(2004년 10월 22일)은 스미스소니언에 기증됐다 | 🟡 |

### 매드맨 "캐러셀 피치" (드라마)

| 내용 | 정확도 |
|---|---|
| 미국 드라마 **매드맨** 시즌 1 마지막 화 **"The Wheel"(2007)** 에 나오는 장면 | ✅ |
| 극 중 Kodak은 이 제품을 "더 휠(The Wheel)"이라고 부르려 하고, 주인공 돈 드레이퍼가 **"캐러셀"** 이라는 이름과 함께 "향수를 일으키는 시간 여행 기계, 돌고 돌아 다시 집으로 돌아오게 하는 기계"라고 소개한다 | ✅ (드라마 내용) |
| **실제 Kodak이 "The Wheel"이라는 이름을 검토했다는 근거는 없다.** 드라마의 각색이다 | ✅ |

## 3. SNS 캐러셀 (콘텐츠 형식)

### 이름의 직접적인 출처: 페이스북 광고

| 내용 | 정확도 |
|---|---|
| 페이스북이 2014년 한 광고 안에 상품 여러 개(3~5개)를 넘겨 보는 **"멀티 프로덕트 광고(Multi-Product Ads)"** 를 냈고, 이후 **"캐러셀 광고"** 로 이름을 바꿨다 | 🟡 (출시 시점이 2014년 6월 / 2014년 말 / 2015년 2월로 자료마다 다름) |
| 페이스북의 한 디자이너가 "상품 나열 말고도 이야기, 비포·애프터, **파노라마**, 캐릭터 등에 쓸 수 있다"는 제안과 함께 이름을 "캐러셀"로 바꾸자고 했고 채택됐다 | ⚠️ (본인이 쓴 글 하나뿐, 독립 확인 없음) |

**참고**: 인스타그램은 2012년부터 페이스북(현 메타) 소속이라, 인스타그램 "캐러셀"은 페이스북 광고 이름을 이어받은 것으로 보는 게 자연스럽다. 다만 이를 직접 밝힌 공식 자료는 찾지 못했다 (⚠️ 추정).

### 인스타그램 캐러셀

| 시점 | 내용 | 정확도 |
|---|---|---|
| 2015년 3월 | 미국에서 일부 광고주에게 **캐러셀 광고** 공개. 인스타그램은 "여러 페이지짜리 잡지 광고를 휴대폰으로 가져온 것", "순서대로 이야기를 전하는 형식"으로 소개 | ✅ |
| 2015년 6월 | 영국, 캐나다, 독일 등 6개국으로 확대. 이후 모든 비즈니스가 직접 집행할 수 있게 됨 | ✅ |
| 2017년 2월 22일 | **일반 사용자도 한 게시물에 사진·영상 최대 10장.** 처음엔 정사각형만 가능, 캡션은 하나, 피드에 파란 점 표시 | ✅ (인스타그램 공식 블로그) |
| 2024년 3월 | 15장 테스트 | 🟡 |
| 2024년 8월 | **최대 20장**으로 확대 | 🟡 (여러 언론 일치) |
| 현재 | 4:5, 3:4 세로형 등 여러 비율. "혼합" 업로드로 장마다 다른 비율 가능 | 🟡 (사용 가이드 기준, 수시로 바뀜) |

**참고**: 인스타그램 공식 발표(2017)는 "캐러셀"이라는 말보다 "한 게시물에 여러 장"이라는 표현을 썼다. "캐러셀"은 광고 형식 이름에서 출발해 사용자와 업계가 널리 쓰는 이름이 됐다.

### 웹 화면의 "캐러셀" 부품

| 내용 | 정확도 |
|---|---|
| 웹사이트에서 이미지나 카드가 옆으로 돌아가며 바뀌는 부품도 "캐러셀"이라고 부른다 (부트스트랩, 머티리얼 디자인 등) | ✅ |
| 이 이름이 언제 처음 쓰였는지는 **기록을 찾지 못했다.** 회전목마에서 따온 것으로 추정된다 | ⚠️ |

## 4. 카드뉴스

| 내용 | 정확도 |
|---|---|
| 여러 장의 카드 이미지에 짧은 글과 그래픽을 담아 정보를 전달하는 **콘텐츠 형식** | ✅ |
| 해외 원조로 **2014년 4월 미국 Vox Media의 "카드 스택"** (질문과 답 카드를 넘기며 읽는 기사)이 꼽힌다 | 🟡 |
| 한국에서는 **2014년 9월 SBS 스브스뉴스**를 시작으로 2014년 말부터 언론사들이 페이스북 등에서 널리 썼다 | 🟡 |
| "카드뉴스"라는 이름과 형식이 한국에서 특히 발달해 "한국적 발명품"이라고 부르는 시각도 있다 | ⚠️ (한 인터뷰 기사의 표현) |

## 5. 캐러셀과 카드뉴스의 관계

| | 캐러셀 | 카드뉴스 |
|---|---|---|
| 무엇인가 | 한 게시물에 여러 장을 넣고 넘겨 보는 **게시 형식** (플랫폼 기능 이름) | 카드 여러 장으로 정보를 전하는 **콘텐츠 장르** |
| 비유 | 그릇 | 그릇에 담는 음식 중 하나 |
| 담기는 것 | 카드뉴스, 인스타툰, 사진 모음, 제품 소개, 튜토리얼, 비포·애프터, 파노라마, 영상 | 정보 전달 카드 |
| 어디서 | 인스타그램, 페이스북, 링크드인 등 | 인스타그램, 페이스북, 블로그, 뉴스레터 등 |

## 6. 캐로킷 브랜딩에 쓸 수 있는 이야기

**안전하게 쓸 수 있는 문장 (✅ 기반)**
- "캐러셀은 원래 회전목마예요. 빙글빙글 돌며 하나씩 보여주는 것."
- "1961년 Kodak은 슬라이드를 회전목마처럼 둥근 트레이에 꽂아 한 장씩 비추는 프로젝터를 '캐러셀'이라고 불렀어요."
- "2017년부터 인스타그램에서 누구나 한 게시물에 여러 장을 넘겨 보여줄 수 있게 됐어요. 지금은 최대 20장까지요."
- "캐로킷은 카드뉴스만이 아니라, 넘겨 보는 모든 콘텐츠(캐러셀)를 위한 키트예요."

**조심해서 쓸 문장**
- 매드맨 장면은 **드라마**라고 밝히고 인용하기 (실제 역사처럼 쓰지 않기)
- 미수라카 발명설, 페이스북 디자이너 작명설은 "~라고 알려져 있다" 정도로만
- Kodak, Carousel, 인스타그램 상표와 로고는 앱 이름, 아이콘, 광고에 쓰지 않기

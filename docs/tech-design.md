## 2. 앱 구조 (모듈)

```
CaroKit (앱)
├─ App        화면 이동: 스플래시 → (튜토리얼) → 홈 → 에디터 / 시리즈 / 템플릿 / 설정 / 휴지통
├─ Document   데이터 모델, 저장·불러오기, 자동 저장, 크래시 복구
├─ Library    시리즈, 디자인 키트, 템플릿, 팔레트, 텍스트 스타일, 폰트 관리
├─ Editor     에디터 화면 조립: 상단 바, 도구 바, 패널, 슬라이드 바
├─ Canvas     렌더러, 선택·변형, 스마트 가이드, 스냅, 오버레이
├─ Drawing    브러쉬 엔진, 손그림 레이어, 올가미, 페인트통
├─ Text       텍스트 배치, 스타일, 캔버스 위 편집
├─ Script     원고 패널, 단락, 캔버스 연결, 흘려넣기
├─ Media      이미지 불러오기·보정, 동영상 편집·재생
├─ Preview    인스타 미리보기 (피드, 그리드, 휴대폰 화면)
└─ Export     JPG, PNG, PDF, MP4, 사진 앱 저장, 공유
```

**핵심 원칙**

1. **손그림 외에는 벡터.** 텍스트, 도형, 펜툴, 말풍선은 모양 정보(글자, 경로)로 저장하고 화면 배율과 내보내기 배율에 맞춰 매번 새로 그린다. 한 번 그린 그림을 늘려 쓰지 않는다. 이미지는 원본을 보관하고 화면용 축소본은 따로 둔다.
2. 화면에 그리는 렌더러와 내보낼 때 그리는 렌더러를 **같은 것**으로 쓴다. 그래야 화면에서 본 그대로 결과물이 나온다. 영상 내보내기도 프레임마다 같은 렌더러로 위 오브젝트를 합성한다.

## 3. 데이터 구조 (요약)

### 프로젝트 파일 (폴더 하나)

```
인스타툰 A 3화.carousel/
├─ project.json     규격, 슬라이드, 오브젝트, 스타일, 원고, 원고-캔버스 연결
├─ media/           이미지 원본, 영상, 오디오
├─ drawings/        손그림 레이어 (그린 영역만 PNG로)
├─ fonts/           프로젝트에 포함한 폰트 (선택)
└─ thumbnail.png    홈 화면 썸네일
```

### 주요 데이터

| 데이터 | 내용 |
|---|---|
| 프로젝트 | 기본 규격, 슬라이드 목록, 오브젝트 목록, 소속 시리즈 |
| 슬라이드 | 순서, 비율(혼합 비율용), 채우기, 레이아웃 그리드 |
| 오브젝트 | **모든 슬라이드가 좌표 공간 하나를 공유** (이어지는 캐러셀). 종류: 텍스트, 도형, 펜툴 경로, 말풍선, 이미지, 동영상, 손그림 레이어, 그룹. 공통 속성: 위치·크기·회전, 불투명도, 블렌드, 클리핑, 효과 |
| 텍스트 | 서식 있는 글자(부분 서식), 텍스트 스타일 참조, 연결된 원고 단락 ID |
| 원고 | 단락 목록 (글자, 스타일, 개별 서식, 슬라이드 구분, 넣을 위치) |
| 라이브러리 | 시리즈, 디자인 키트, 템플릿, 팔레트, 텍스트 스타일, 가져온 폰트 (프로젝트 밖에 따로 저장) |

## 4. 개발 순서

UI 디자인은 개발과 **동시에** 진행한다. 개발은 기본 모양으로 먼저 만들고, 디자인이 나오면 바꿔 끼운다.

| 단계 | 내용 | 결과 |
|---|---|---|
| **M0 준비** | Mac 확인, Xcode 설치, 아이패드 개발자 모드 켜기, 이 저장소에 Xcode 프로젝트 만들기 | 빈 앱이 내 아이패드에서 실행됨 |
| **M1 위험 검증 시제품** | ① 브러쉬 엔진 ② 캔버스 위 한글 텍스트 편집 ③ 영상 + 블렌드 합성 내보내기 | 가장 어려운 3가지가 되는지 직접 써보고 확인 |

**M1 브러쉬 엔진 판정** (M1 끝에 결정)

- 시제품 범위: 펜, 붓펜, 형광펜, 지우개 + 필압 켜기/끄기 + 직선 보정 + 실행 취소
- 통과 기준: 내 아이패드에서 프로크리에이트와 나란히 써 봤을 때 **반응 속도와 선 느낌이 거슬리지 않을 것**
- 통과 → 직접 만든 엔진으로 계속 (질감 브러쉬, 올가미, 기울기는 그다음)
- 실패 → 첫 버전은 애플 기본 그리기 도구(PencilKit)로 출시하고, 직접 만든 엔진은 이후 버전으로 미룬다. 이때 빠지는 기능: 직선 보정, 형광펜 겹침 규칙, 질감 브러쉬, 브러쉬별 기울기 켜기/끄기, 픽셀 방식(페인트통 등)
- **M2 전에 반드시 결정한다.** 손그림 저장 방식(픽셀 / PencilKit 선 데이터)이 달라서 나중에 바꾸면 기존 작업물 변환이 필요하다
| **M2 뼈대** | 프로젝트 저장·열기, 홈, 에디터 틀, 슬라이드(이어 보기·한 장씩), 이미지·도형·텍스트 기본, 레이어, JPG 내보내기 | 간단한 캐러셀을 만들어 저장할 수 있음 |
| **M3 P0 완성** | 원고, 손글씨, 동영상, 미리보기, 시리즈·템플릿, 단축키 | **내 아이패드에서 실제로 써보기** |
| **M4 P1 + 데모** | P1 기능, 버그 수정, Apple Developer 가입, TestFlight 배포 | 팔로워·지인 데모 |
| **M5 출시** | 앱 아이콘, 스크린샷, 설명, 개인정보처리방침, 심사 | 앱스토어 출시 |

## 5. 개발 방식

- **저장소**: 이 GitHub 저장소에 Xcode 프로젝트를 추가하고, 문서와 코드를 함께 관리한다.
- **Mac에서 Claude Code 사용**: Mac에서 Claude Code를 실행하면 코드 작성, 빌드, 시뮬레이터 화면 확인, 테스트까지 할 수 있다.
- **실기기 확인은 필수**: 펜슬 필압, 기울기, 반응 속도, 더블탭은 시뮬레이터로 확인할 수 없다. 아이패드를 Mac에 연결해 Xcode에서 실행 버튼을 누르면 설치된다.
- **테스트**: 데이터 저장·불러오기, 원고 흘려넣기 규칙, 내보내기 분할(경계 오브젝트) 같은 로직은 자동 테스트를 만든다.

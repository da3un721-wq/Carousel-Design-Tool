# 캐로킷 (CaroKit): 기능 명세서 (v0.10)

> 프로젝트 가명: **캐로킷 (CaroKit)** · "캐러셀에 필요한 도구가 다 들어있는 키트" · 출시명은 출시 전에 상표와 앱스토어 확인 후 확정

> **목표: 캐러셀 만드는 사람들의 완벽한 어시스트 툴**
>
> 아이패드에서 캐러셀과 인스타툰을 한 번에 만드는 디자인 툴
> Figma(레이아웃) + Illustrator(정밀 편집) + Procreate(손그림) + Canva(템플릿)
>
> **플랫폼: iPad 전용 네이티브 앱 (Swift)** · 개발 구조는 [tech-design.md](tech-design.md)

### 변경 이력
- **v0.10** (10월 21일 손 스케치 반영, 와이어프레임 v0.2): 시리즈 설정 먼저 보여주기(SR-13), 홈 카드 장 표시 동그라미 최대 6개, 카드 모서리 4px. 홈은 **핀터레스트식 4칸**(PJ-03), 보기 탭(PJ-10), 설정 팝업과 내 프로필(PJ-11). **새 프로젝트는 설정 없이 바로 에디터**(PJ-01). 시리즈 제목 형식(SR-11), 시리즈 브러쉬(SR-12), 새 회차에 시리즈 설정 먼저 적용(SR-08). 배경·비율은 에디터 아래 오른쪽 버튼(CV-03, CV-10, CV-15). 레퍼런스 창(CV-18). 내보내기에서 시리즈 지정(EX-11). 템플릿·레퍼런스 보관 탭은 추후(TP-10). 18장 UI 기본안 갱신
- **v0.9**: 피드 계획과 인스타 계정 연동(14-1장, FP-01~08, 출시 후) 추가. 홈 프로젝트 목록을 **인스타 프로필 그리드 모양**으로 (PJ-03). 목표 문장 추가. 한글 무료 폰트 기본 제공 방침과 폰트 라이선스 고지(FT-09), 처음 쓸 때 내려받기(FT-10), 무료 폰트 찾기 안내(FT-11) 추가 ([폰트 레퍼런스](references/fonts.md)). **손그림 외 모든 오브젝트는 벡터 방식**으로 품질 기준에 명시 (경쟁 앱 SWVY에서 텍스트를 키우면 흐려지는 문제 확인). 큰 이미지는 화면에만 줄인 사본을 쓰고 내보내기는 원본으로. 디자인 소스(15-1장, AS-01~06) 추가, 범위는 기본 기능 완성 후 다시 결정
- **v0.8**: **iPad 네이티브 앱 전용으로 전환.** 웹/앱 "구현 단계" 표시 삭제. 펜슬 더블탭·스퀴즈, 설치 폰트, 배경 제거 등 앱 단계 기능을 일반 기능으로 정리. 동영상 10초 제한은 기술 제약이 아닌 첫 버전 범위로 유지. PDF는 글자 선택이 되는 방식으로 변경. 미리보기 실제 크기는 아이패드 모델 자동 인식
- **v0.7**: 원고 기능 추가 (9-1장, SC-01~20). 원고 패널, 단락 나누기, 단락 스타일, 드래그 앤 드롭, 원고와 캔버스 연결, 넣을 위치 지정, 슬라이드 구분선과 자동 흘려넣기

- **v0.5**: 손그림은 픽셀 방식으로 확정. 1단계 동영상은 슬라이드당 최대 10초
- **v0.4**: 동영상 삽입·기본 편집·MP4 내보내기를 P0으로 올림 (핵심 기능). 오디오 넣기, 경계 동영상 자르기는 P1 유지

- **v0.2**: 규격 가로/세로 전환과 16:9 추가, 시리즈 관리와 시리즈 디자인 키트, 한 장씩/이어 보기 모드, 인스타 혼합 비율(가로 사진 여백) 반영, 휴대폰 화면 미리보기, Figma식 수치 입력, 펜툴, 말풍선 상세, 텍스트 단위를 Figma와 동일하게, 필압/기울기 개별 켜기, 형광펜, 직선 보정

## 0. 읽는 법

### 우선순위
| 표기 | 뜻 |
|---|---|
| **P0** | 혼자 써보기 위한 최소 기능 (MVP) |
| **P1** | 배포 전에 있어야 하는 기능 |
| **P2** | 출시 후 추가해도 되는 기능 |

### 플랫폼
- iPad 전용 네이티브 앱 (Swift). 애플펜슬, 블루투스 키보드 지원
- 개발과 설치에는 Mac(Xcode)이 필요. 출시 전 테스트는 내 아이패드 직접 설치(무료) → TestFlight(Apple Developer 가입 후)

### 용어
- **시리즈**: 여러 프로젝트를 묶는 단위 (예: 인스타툰 1화, 2화, 3화…). 선택 사항
- **프로젝트**: 캐러셀 한 세트 (게시물 1개)
- **슬라이드**: 캐러셀의 한 장. Figma의 프레임과 같은 개념
- **오브젝트**: 캔버스 위의 모든 요소 (이미지, 텍스트, 도형, 손그림, 동영상)
- **편집 모드 / 손글씨 모드**: 두 가지 작업 모드. 전환할 수 있음
- **디자인 키트**: 시리즈마다 저장하는 템플릿, 팔레트, 즐겨찾기 폰트, 텍스트 스타일, 레이아웃 프리셋 묶음

## 1. 프로젝트 관리

| ID | 기능 | 상세 | 우선 |
|---|---|---|---|
| PJ-01 | **새 프로젝트: 바로 시작** | 홈 첫 칸 "+ 새 프로젝트"를 누르면 **설정 단계 없이 바로 에디터**. 규격(아래 규격표, 세로/가로, 직접 입력)은 에디터 아래 오른쪽 "비율" 버튼에서 언제든 바꿈. 기본 비율 ⚠️ 미정 (스케치의 "3:4" 확인 필요) | P0 |
| PJ-02 | 슬라이드 수 | 처음 만들 때 장수 선택, 이후 추가/삭제 가능. **최대 장수는 인스타 최대치**(현재 20장, 인스타가 바꾸면 설정값만 수정) | P0 |
| PJ-03 | **프로젝트 목록: 핀터레스트 그리드** | 가로 **4칸**, 칸 너비 고정, 세로는 **프로젝트 비율대로**(4:5, 3:4, 1:1, 16:9가 섞여도 자연스럽게). 첫 칸은 "+ 새 프로젝트". 카드 아래 제목 + ··· 메뉴(PJ-04), 카드 안에서 좌우로 밀면 슬라이드 넘겨 보기. **장 표시 동그라미는 최대 6개**, 6장보다 많으면 끝 동그라미가 점점 작아져 더 있다는 걸 보여줌 (인스타 방식). 카드 모서리는 아주 살짝(4px) 둥글게. 정렬: 최근 수정순 / 이름순. (v0.9의 인스타 그리드 안은 미리보기의 프로필 그리드 IG-04로) | P0 |
| PJ-04 | 이름 변경, 복제, 삭제 | 삭제는 휴지통을 거쳐 30일 뒤 영구 삭제 | P0 / 휴지통 P1 |
| PJ-05 | 자동 저장 | 변경 후 몇 초 안에 기기에 자동 저장 | P0 |
| PJ-06 | 프로젝트 파일 내보내기/가져오기 | 프로젝트 전체(이미지, 폰트 포함)를 파일 하나로 저장하고 불러오기. 백업과 기기 이동용 | P0 |
| PJ-07 | 크래시 복구 | 앱이 갑자기 꺼져도 마지막 상태로 복구 | P1 |
| PJ-08 | 클라우드 동기화 | iCloud로 아이패드와 맥 동기화 | P2 |
| PJ-10 | **홈 보기 탭** | 홈 오른쪽 위: 전체 프로젝트 / 시리즈별 / 템플릿·레퍼런스(추후, TP-10). 아이콘 + 이름 | P0 |
| PJ-11 | **설정 팝업과 내 프로필** | 홈 왼쪽 위 "CaroKit ▾"를 누르면 팝업: 내 프로필(미리보기 인스타 화면에 쓰는 사진·아이디, 기기에만 저장) + 설정 항목 + 가져오기 · 휴지통 · 정보 | P1 |
| PJ-09 | 규격 변경 | 만든 뒤에도 규격 변경 가능. 오브젝트 위치는 비율에 맞춰 조정할지 그대로 둘지 선택 | P1 |

### 규격표 (가로 폭 1080px 기준)

| 비율 | 세로형 | 가로형 | 인스타 피드에서 |
|---|---|---|---|
| 4:5 | 1080×1350 | 5:4 → 1080×864 | 세로형: 기본 권장 규격 |
| 3:4 | 1080×1440 | 4:3 → 1080×810 | 세로형: 프로필 그리드에 잘림 없이 맞음 |
| 1:1 | 1080×1080 | (전환 없음) | 그대로 표시 |
| 16:9 | 9:16 → 1080×1920 | 1080×608 | 가로형: 위아래 여백과 함께 표시 / 세로 9:16: 피드에서 위아래가 잘림 → 경고 표시 |
| 직접 입력 | | | 인스타 허용 범위를 벗어나면 경고 |

> 인스타 규격(허용 비율, 잘림 방식, 최대 장수)은 자주 바뀌므로 개발 시점과 출시 전에 인스타 앱에서 다시 확인한다.

## 2. 시리즈와 디자인 키트

프로젝트는 캐러셀 한 세트 단위로 관리하고, 원하면 시리즈로 묶을 수 있음. 시리즈 없이 프로젝트만 써도 됨.

| ID | 기능 | 상세 | 우선 |
|---|---|---|---|
| SR-01 | 시리즈 만들기 | 이름, 대표 이미지, 메모. 이름 변경, 삭제(안의 프로젝트는 "시리즈 없음"으로 이동) | P0 |
| SR-02 | 프로젝트를 시리즈에 넣기/빼기 | 드래그 또는 메뉴에서 이동. 프로젝트는 시리즈 하나에만 속함 | P0 |
| SR-03 | 시리즈 화면 | 홈 "시리즈별" 보기: 폴더 탭 모양 카드(최근 회차 3장 미리보기). 시리즈 상세: 이름(폴더 탭) · 제목 형식(SR-11) · **시리즈 설정 4칸(비율 · 폰트 · 컬러 · 브러쉬, 눌러 들어가 일괄 설정)** · 회차 격자(첫 칸 "+ 새 회차"), 순서 변경 | P1 |
| SR-04 | **시리즈 템플릿** | 시리즈 전용 템플릿 저장. 시리즈 안에서 새 프로젝트를 만들면 이 템플릿으로 바로 시작 | P0 |
| SR-05 | **시리즈 팔레트** | 시리즈 전용 컬러 팔레트 | P1 |
| SR-06 | **시리즈 즐겨찾기 폰트** | 시리즈에서 쓰는 폰트를 목록 맨 위에 고정 | P1 |
| SR-07 | 시리즈 텍스트 스타일, 레이아웃 프리셋 | 제목/본문 스타일, 가이드와 그리드 설정을 시리즈 단위로 저장 | P1 |
| SR-08 | 새 회차 만들기 | "+ 새 회차": 시리즈 비율 · 템플릿으로 시작하는 에디터가 열리고, 편집하는 동안 시리즈 설정을 먼저 보여줌(SR-13). 이름은 제목 형식(SR-11)대로 자동 | P1 |
| SR-13 | **시리즈 설정 먼저 보여주기** | 시리즈 회차를 편집할 때 고르는 곳마다 시리즈에서 정해 둔 것을 맨 위에 ("시리즈" 표시): **색** 고르기 → 시리즈 팔레트 먼저 / **텍스트** 넣기 → 시리즈 텍스트 스타일(폰트 · 크기 · 자간 · 행간) 골라 바로 넣기 / **손글씨** → 시리즈 브러쉬 먼저 / **요소** → 시리즈 말풍선 · 도형 스타일 먼저. 시리즈가 없는 프로젝트는 내 스타일 · 내 팔레트가 같은 자리에 | P1 |
| SR-11 | **제목 형식** | 시리즈마다 제목 템플릿 저장: **넘버링**(오늘의 고양이 #13) 또는 **부제**(오늘의 고양이 · 부제). 새 회차 이름과 내보내기 파일 이름(EX-11)에 자동 적용 | P1 |
| SR-12 | 시리즈 브러쉬 | 시리즈에서 쓰는 브러쉬 설정 묶음 (DR-19 프리셋과 연결) | P1 |
| SR-09 | 디자인 키트 변경 반영 | 키트를 고쳤을 때 기존 회차에도 반영할지 선택 | P2 |
| SR-10 | 시리즈 내보내기 | 시리즈 전체(프로젝트 + 키트)를 파일 하나로 백업 | P2 |

## 3. 캔버스와 슬라이드

| ID | 기능 | 상세 | 우선 |
|---|---|---|---|
| CV-01 | **이어 보기 모드** | 슬라이드를 가로로 이어 붙여 한 화면에 보여줌. 경계선 표시 | P0 |
| CV-02 | **한 장씩 보기 모드** | 슬라이드 한 장만 크게 표시. 경계를 넘는 오브젝트는 이 장에 들어오는 부분만 보임 (실제 결과물과 같은 모습) | P0 |
| CV-03 | 보기 모드 전환 | 에디터 아래 오른쪽 [한 장씩 · 이어 보기] 버튼, 키보드 단축키(⇧S) | P0 |
| CV-04 | **이어지는 캐러셀** | 오브젝트가 슬라이드 경계를 넘어도 됨. 넘기면 파노라마처럼 이어져 보임 | P0 |
| CV-05 | **경계 오브젝트 자동 자르기** | 경계에 걸친 이미지, 도형, 텍스트, 손그림은 내보낼 때 장별로 알아서 잘림. 원본 오브젝트는 하나로 유지되어 계속 편집 가능 | P0 |
| CV-06 | 경계 동영상 자동 자르기 | 경계에 걸친 영상도 장별 영상으로 나눠 내보냄 (같은 시간에 재생되도록) | P1 |
| CV-07 | **슬라이드 이동** | 키보드 ← → (오브젝트가 선택되지 않았을 때), 스와이프, 하단 슬라이드 목록 탭. 이어 보기 모드에서는 해당 장으로 화면 이동. **스와이프 규칙**: 한 장씩 보기 모드에서 화면 맞춤 상태일 때만 두 손가락으로 빠르게 튕기면 넘김. 확대한 상태에서는 두 손가락 드래그가 화면 이동 (사진 앱과 같은 방식) | P0 |

## 18. 화면 구성 (UI) 기본안

> 와이어프레임 v0.2: [CaroKit Figma › WireFrame v0.2](https://www.figma.com/design/fRGnDrQsZ5Iyh8eUxt5sOx). 스타일 기준은 [디자인 원칙](design-principles.md) 2-1장

- **상단 바 공통**: 진한 띠 하나에 칸이 붙은 형태. 지금 보는 탭 · 열린 칸(레이어, 미리보기)만 흰색으로 뚫려 아래 화면과 이어짐 (폴더 탭)
- **홈**: 왼쪽 위 "CaroKit ▾"(설정 팝업), 오른쪽 위 보기 탭(전체 / 시리즈 / 템플릿·레퍼런스 추후). 전체는 핀터레스트식 4칸 그리드, 첫 칸 "+ 새 프로젝트"
- **시리즈 상세**: 이름 · 제목 형식 · 시리즈 설정 4칸(비율, 폰트, 컬러, 브러쉬) · 회차 격자
- **에디터 상단 바**: 뒤로, 프로젝트 이름(누르면 이름 바꾸기), 실행 취소/다시 실행, 레이어, 미리보기, 내보내기
- **왼쪽 도구 바**: 선택, 텍스트, 원고, 미디어(사진·영상), 손글씨, 요소(말풍선·도형·펜·클리핑 등), 맨 아래 레퍼런스. 손글씨를 누르면 옆에 브러쉬 도구가 펼쳐짐
- **원고 패널** (도구 바 옆, 열고 닫기): 열면 캔버스가 좁아짐
- **오른쪽 디자인 패널**: 무언가를 선택했을 때만 나타남 (속성, 채우기, 테두리, 텍스트, 효과)
- **하단**: 왼쪽 슬라이드 목록(썸네일, 추가, 순서 변경), 오른쪽 [한 장씩 · 이어 보기] · 배경 · 비율 · 확대
- 설정: 다크/라이트, 왼손잡이 배치(도구 바 좌우 반전, P2)

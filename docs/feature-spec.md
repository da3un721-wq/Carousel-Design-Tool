# 캐러셀 디자인 툴: 기능 명세서 (v0.1)

> 아이패드에서 캐러셀과 인스타툰을 한 번에 만드는 디자인 툴
> Figma(레이아웃) + Illustrator(정밀 편집) + Procreate(손그림) + Canva(템플릿)

---

## 0. 읽는 법

### 우선순위
| 표기 | 뜻 |
|---|---|
| **P0** | 혼자 써보기 위한 최소 기능 (MVP) |
| **P1** | 배포 전에 있어야 하는 기능 |
| **P2** | 출시 후 추가해도 되는 기능 |

### 구현 단계
| 표기 | 뜻 |
|---|---|
| 🌐 | **1단계(아이패드만으로 개발)** 에서 구현할 수 있음 |
| 🍎 | **2단계(맥북에서 앱으로 포장)** 이후에 구현할 수 있음 |
| 🌐→🍎 | 1단계에서 기본형, 2단계에서 완성형 |

### 용어
- **프로젝트**: 캐러셀 한 세트 (게시물 1개)
- **슬라이드**: 캐러셀의 한 장
- **오브젝트**: 캔버스 위의 모든 요소 (이미지, 텍스트, 도형, 손그림, 동영상)
- **편집 모드 / 손글씨 모드**: 두 가지 작업 모드. 전환할 수 있음

## 17. 화면 구성 (UI) 기본안

- **상단 바**: 뒤로가기(프로젝트 목록), 프로젝트 이름, 실행 취소/다시 실행, 모드 전환(편집/손글씨), 미리보기, 내보내기
- **왼쪽 도구 바**: 선택, 텍스트, 도형, 이미지, 동영상 / 손글씨 모드에서는 브러쉬, 지우개, 올가미, 색상
- **오른쪽 패널** (접기 가능): 속성(좌표, 크기, 텍스트, 색, 효과) / 레이어 탭
- **하단**: 슬라이드 목록 (썸네일, 추가, 순서 변경)
- 설정: 다크/라이트, 왼손잡이 배치(도구 바 좌우 반전, P2)

# 캐로킷 (CaroKit): 정보 구조 (IA) v0.2 · 사용 흐름

> **다이어그램(FigJam)**: [캐로킷 IA · 사용 흐름](https://www.figma.com/board/Mp6utyKiDJWgS7BKSOIa1j)
>
> 단순한 화면 나열이 아니라, 사용자가 이 앱을 **어떤 순서로 어떻게 쓰는지**를 왼쪽에서 오른쪽 흐름으로 보여준다.
> 기준: 기능 명세서 v0.8 · iPad 네이티브 앱

### 변경 이력
- **v0.2**: 사용 흐름 중심으로 전면 재설계. 첫 실행 안내(S0) 삭제, 첫 실행 시 튜토리얼 분기만 추가(내용은 추후 설계). 이전 IA 다이어그램과 와이어프레임 삭제
- v0.1: 화면 목록 중심 IA (폐기)

## 1. 읽는 법 (범례)

| 구분 | 표시 | 뜻 |
|---|---|---|
| **화면** | 사각형, 색 = 영역 | 회색 = 보관함 · 관리 / 파랑 = 제작(에디터) / 보라 = 원고 / 빨강 = 출력(미리보기) |
| **사용자 행동 · 기능** | 둥근 알약, 흰 바탕 (테두리 색 = 영역) | 사용자가 누르거나 하는 일 |
| **시트 · 팝업 · 메뉴** | 둥근 사각형, 노랑 | 화면 위에 뜨는 창 |
| **알럿 · 경고** | 육각형, 주황 | 확인 창, 경고 배너, 완료 알림 |
| **판단** | 마름모 | 조건에 따라 흐름이 갈림 (YES / NO) |
| **외부 앱 · 시스템** | 평행사변형, 초록 | 사진 앱, 파일 앱, 공유 시트, 인스타그램 앱 |
| **보류** | 양옆 줄 사각형, 연회색 | 추후 설계 (튜토리얼) |
| **시작 · 끝** | 원, 노랑 | 앱 실행 / 업로드 완료 |

---

## 2. 전체 흐름 한 줄 요약

**앱 실행 → (첫 실행이면 튜토리얼) → 홈 → 프로젝트 만들기 / 열기 → 에디터에서 제작 → 미리보기 → 내보내기 → 인스타 업로드**

---

## 3. 흐름별 상세

### ① 시작

```
앱 실행 → 스플래시 → ◇ 첫 실행인가?
                        ├ YES → [튜토리얼 · 추후 설계] → 홈
                        └ NO  → 홈
```

### ② 홈 (프로젝트 보관함)에서 갈 수 있는 곳

| 행동 | 이어지는 흐름 |
|---|---|
| 새 프로젝트 | 새 프로젝트 시트 → 규격 · 세로/가로 · 장수 선택 → ◇ 시리즈에 넣을까? (YES → 시리즈 선택) → 템플릿 선택 → **에디터** |
| 프로젝트 열기 | → **에디터** |
| 시리즈 상세 | 다음 회차 만들기 → **에디터** / 디자인 키트 → 시리즈 템플릿 · 팔레트 · 즐겨찾기 폰트 · 텍스트 스타일 · 레이아웃 프리셋 · ⬡ 기존 회차 반영 확인 |
| 템플릿 보관함 | 템플릿으로 시작 → 새 프로젝트 시트 |
| 가져오기 | 파일 앱 → **에디터** |
| 카드 길게 누르기 메뉴 | 이름 변경 · 복제 · 시리즈 이동 / 삭제 → 휴지통 |
| 새 시리즈 | 새 시리즈 시트 |
| 휴지통 | 복원 / 영구 삭제 → ⬡ 영구 삭제 확인 |
| 설정 | 일반(테마, 왼손잡이) · 펜슬과 제스처 · 키보드 단축키 · 미리보기 기기 모델 · 폰트 관리 · 저장 · 백업 · iCloud · 정보 |

### ③ 에디터 (제작)

에디터에서 시작하는 7갈래 흐름. 만드는 흐름은 모두 **오브젝트 선택 → 디자인 패널**로 모인다.

**원고로 텍스트 넣기**
```
원고 패널 → 원고 쓰기 · 붙여넣기 → 단락 나누기 · 슬라이드 구분 → 단락 스타일 지정(일괄 · 개별)
→ ◇ 어떻게 넣을까?
   ├ 끌어다 놓기 → 캔버스로 드래그 앤 드롭 ─┐
   ├ 위치 지정   → 위치 지정 후 넣기 ────────┤
   └ 자동        → 자동 흘려넣기 → ◇ 슬라이드가 모자라나? (YES → ⬡ 슬라이드 추가 확인)
                                                         ↓
                              원고와 연결된 텍스트 생성 → 오브젝트 선택
```

**편집 모드 도구로 만들기**
```
편집 모드 도구 ├ 텍스트 · 도형/펜툴 · 말풍선 → 캔버스에 놓기 → 오브젝트 선택
               ├ 이미지 넣기 → 사진 앱 · 파일 앱 → 크롭 모드 → 오브젝트 선택
               └ 동영상 넣기 → 사진 앱 · 파일 앱 → ◇ 10초 초과? (YES → 구간 · 배속 시트) → 오브젝트 선택
```

**손글씨**
```
손글씨 모드 → 브러쉬 설정 → 그리기(필압 · 직선 보정) → 지우개 · 올가미 · 페인트통 → 편집 모드로 전환 → 오브젝트 선택
```

**오브젝트 다듬기**
```
오브젝트 선택 ├ 디자인 패널 → 위치·크기·정렬 / 불투명도·블렌드 / 채우기·테두리·효과(→ 색상 선택기)
              │               / 텍스트·배경 박스(→ 폰트 선택기) / 이미지 보정 / 동영상·오디오
              └ 길게 누르기 메뉴
```

**슬라이드 관리**
```
슬라이드 바 ├ 슬라이드 추가 · 복제 · 순서
            ├ 이어 보기 / 한 장씩
            └ 슬라이드 선택 → 슬라이드 채우기 · 비율 · 그리드 → ◇ 비율이 섞였나? (YES → ⬡ 혼합 비율 경고)
```

**레이어 패널**: 순서 · 그룹 · 클리핑 · 숨김 · 잠금

**더보기 메뉴**: 규격 변경 시트 · 템플릿으로 저장 시트 · 보기 옵션(눈금자, 그리드, 잘림 영역) · 단축키 목록

### ④ 출력과 업로드

```
미리보기 → 피드 넘기기(휴대폰 화면) · 프로필 그리드 · 혼합/기본 업로드 비교
   ↓
내보내기 → 내보내기 시트 → 범위 · 형식 · 크기 선택 → ◇ 영상 슬라이드 있나? (YES → MP4 만들기)
→ ◇ 저장 위치 ├ 사진 앱 → ⬡ 내보내기 완료 알림 → 인스타에 업로드 → 완료
              ├ 파일 앱
              ├ 공유 시트
              └ 인스타그램 앱 → 인스타에 업로드 → 완료
```

## 4. 정한 것

| # | 결정 | 이유 |
|---|---|---|
| 1 | 첫 실행 안내 화면은 없애고, **첫 실행일 때만 튜토리얼**로 가는 분기만 둔다 | 튜토리얼 내용은 앱 설계가 끝난 뒤 설계 (보류) |
| 2 | 에디터의 만드는 흐름은 모두 **오브젝트 선택 → 디자인 패널**로 모인다 | 무엇을 만들든 다듬는 방법이 같음 (Figma 방식) |
| 3 | 원고 패널은 에디터 **왼쪽**, 열고 닫기 | 오른쪽 디자인 패널과 동시에 보면서 작업 |
| 4 | 영상은 넣을 때 **10초 초과면 구간 · 배속 시트**로 | 명세서 VD-01, VD-11 |
| 5 | 내보내기 후 사진 앱 저장이 기본 경로, 인스타 업로드는 **인스타그램 앱**에서 | 인스타 직접 업로드는 API 제약이 많음 |

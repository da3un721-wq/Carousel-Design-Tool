# 캐로킷 (CaroKit)

> 캐러셀에 필요한 도구가 다 들어있는 키트.
> 인스타 캐러셀과 인스타툰을 iPad 한 곳에서 만드는 디자인 툴 (Figma + Illustrator + Procreate + Canva)

- 플랫폼: iPad 전용 네이티브 앱 (Swift)
- 상태: 기획 · 설계 단계
- 가명이며, 출시명은 출시 전에 확정
